## Development

Prefer working locally? You need Bun 1.x. Install Bun from [bun.sh](https://bun.sh), then use the repository lockfile for a reproducible setup.

```sh
git clone <this-repository-url>
cd <repository-name>
bun install --frozen-lockfile
bun run dev
```

For verification, run `bun run lint` and `bun run build`. CI should pin an explicit Bun 1.x version, install with `--frozen-lockfile`, and run both checks. Do not generate an npm lockfile or switch package managers without a new decision in `DECISIONS.md`.

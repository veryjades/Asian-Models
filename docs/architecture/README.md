# Architecture Notes

This directory holds phase-specific design records that expand approved decisions without replacing them.

## Source-of-truth order

1. `DECISIONS.md` controls approved architecture and product choices.
2. `DEVELOPMENT_PLAN.md` controls phase scope and gates.
3. `TASKS.md` controls current execution state and blockers.
4. Files in this directory provide supporting diagrams, data models, interface contracts, threat models, and rollout notes.

Create a note here only when the active phase requires it. Each note must link to its decision IDs, phase, owner, status, and related task IDs. A note cannot override an approved decision; propose a new decision instead.
